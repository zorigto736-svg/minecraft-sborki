# Сборки Minecraft для Prism

Сборки для нашего сервера на двоих. Моды и настройки обновляются сами при каждом
запуске игры: Prism сверяется с этим списком и докачивает то, что изменилось.

## Сборки

| Сборка | Игра | Что внутри | Ссылка для Prism |
|---|---|---|---|
| Сервер на двоих — быстрая | 26.3, Fabric | Fabulously Optimized (плавнее, больше кадров) + Bobby (дальняя прорисовка) | `https://raw.githubusercontent.com/zorigto736-svg/minecraft-sborki/main/prism/server-na-dvoih.zip` |

Сервер: `Smerti999.aternos.me` — уже в списке серверов внутри сборки.

## Как поставить (один раз на каждую сборку)

1. Скачать Prism Launcher: <https://prismlauncher.org/download/> и войти в свой аккаунт
   Microsoft («Учётные записи» → «Управление» → «Добавить Microsoft»).
2. «Добавить сборку» → слева «Импорт» → вставить ссылку из таблицы → OK.
3. Запустить сборку двойным щелчком. Первый раз откроется окошко загрузки модов
   (около 45 МБ, минута-две), потом игра.

Дальше ничего делать не нужно: если в сборке что-то поменялось, окошко при запуске
само скачает изменения.

## Если что-то не так

- Окошко загрузки пишет ошибку — запустить ещё раз; если повторяется, написать мне.
- Пускает на сервер, но мир пустой и через несколько секунд выкидывает — провайдер
  режет зарубежный сервер, написать мне.
- Играть с домашнего интернета, не с мобильного: при «белых списках» Minecraft не пускает.

## Как устроено (для правки)

- `server-na-dvoih/` — сборка в формате [packwiz](https://packwiz.infra.link/): список модов
  со ссылками на Modrinth и суммами, плюс файлы настроек.
- `prism/server-na-dvoih.zip` — пустая игра 26.3 с Fabric и установщиком
  [packwiz-installer](https://github.com/packwiz/packwiz-installer), который запускается
  перед игрой (Prism → «Настройки сборки» → «Свои команды»).
- `tools/build_pack.py` — собирает и то и другое заново: основа — Fabulously Optimized
  с Modrinth, сверху свои моды (`extra_mods`) и файлы (`extra_files`).
  Запуск: `python3 -I tools/build_pack.py <папка для скачанного>`.
- `servers.dat` кладётся только если его ещё нет, чтобы не затирать свой список серверов.
